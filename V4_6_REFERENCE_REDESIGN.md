# PantryLoop V4.6 — Reference UI Redesign

This build keeps the working V4.5 Firebase/Auth/Firestore behavior and redesigns the visual layer to match the supplied reference screenshots more closely.

## Visual changes
- Dark forest-green compact sidebar with clearer active states.
- Cream/paper workspace with smaller professional cards and subtle borders/shadows.
- Centered compact top header with `SMART KITCHEN • ZERO WASTE` and module title.
- Dashboard hero, impact card, expiring list, recipe match, inventory health and shopping preview restyled to the reference composition.
- Inventory metrics, filters and table made denser and more professional.
- Receipt scanner visually aligned with the same design system.
- Recipe Synthesizer gets a calm botanical background, compact controls and green synthesis panel.
- Shopping List gets a clean single-panel layout with a subtle botanical background.
- Waste Tracker uses copper-accent KPI cards and a vertical waste-cause chart.
- Insights gets icon KPIs, multitone trend bars and colored next-action cards.
- Login/Signup keeps the working Firebase flow but uses a more editorial split-screen composition.
- Responsive desktop/tablet/mobile layouts preserved.

## Functional baseline
No Firebase collection paths, Authentication flow, Firestore security model, user data separation, cloud persistence or CRUD contracts were intentionally changed by this redesign.
